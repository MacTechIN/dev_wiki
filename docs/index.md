# Dev Wiki 개요

Dev Wiki는 사내 개발팀의 기술 지식, 업무 절차, API/아키텍처 문서, 운영 Runbook, 의사결정 기록을 입력하고 분석한 뒤 정리해 보관하는 문서 포털입니다.

## 목표

- 개발 지식과 운영 절차를 한 곳에 모읍니다.
- 신규 구성원이 빠르게 온보딩할 수 있게 합니다.
- 장애 대응, 배포, API 변경 같은 반복 업무의 기준 문서를 제공합니다.
- 중요한 기술 결정은 의사결정 기록으로 남깁니다.
- Git 기반 변경 이력으로 문서 품질을 관리합니다.

## 문서 분류

- 개발 문서: 아키텍처, API, 데이터 모델, 시스템 설계
- 운영 문서: 배포, 모니터링, 장애 대응, 롤백
- 표준/가이드: 코딩 표준, Git 전략, 리뷰 체크리스트
- 의사결정 기록: DEC 문서

## 사용 방법

1. 좌측 사이드바에서 문서 분류를 선택합니다.
2. 상단 검색창에서 필요한 키워드를 검색합니다.
3. 새 문서는 Markdown으로 작성하고 Git으로 변경 이력을 남깁니다.
4. 중요한 결정은 의사결정 기록에 별도 문서로 보관합니다.
