# 코딩 표준

이 문서는 개발팀 공통 코딩 표준의 시작점입니다.

## 기본 원칙

- 읽기 쉬운 코드를 우선합니다.
- 변경 범위를 작게 유지합니다.
- 공통 로직은 테스트와 함께 추출합니다.
- 예외 처리는 사용자 영향과 운영 관측 가능성을 함께 고려합니다.
- 보안과 개인정보 영향을 코드 리뷰에서 반드시 확인합니다.

## 리뷰 체크

- 요구사항을 충족하는가?
- 테스트가 충분한가?
- 오류 메시지와 로그가 운영에 도움이 되는가?
- 보안 또는 개인정보 영향이 있는가?
- 새 의존성이 꼭 필요한가?

## 문서화 기준

새로운 아키텍처, API, 운영 절차, 장애 대응 방식이 생기면 코드와 함께 Wiki 문서를 갱신합니다.
