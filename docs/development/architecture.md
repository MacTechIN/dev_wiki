# 시스템 아키텍처

이 문서는 시스템 아키텍처를 정리하는 기준 문서입니다.

## 작성 항목

- 시스템 목적
- 주요 사용자와 액터
- 컴포넌트 구성
- 데이터 흐름
- 외부 연동
- 장애 지점과 복구 전략

## 다이어그램 예시

```mermaid
flowchart LR
  User[사용자] --> Web[Web App]
  Web --> API[API Server]
  API --> DB[(Database)]
```

## 운영 기준

아키텍처 변경이 배포, 보안, 데이터 모델에 영향을 주면 의사결정 기록을 함께 작성합니다.

## 문서 작성 팁

- 그림만 남기지 말고 각 컴포넌트의 책임을 표로 정리합니다.
- 장애가 발생했을 때 어느 로그와 지표를 확인할지 적습니다.
- 외부 시스템 의존성은 인증 방식과 장애 대응 방법을 함께 기록합니다.
